## 填写示例：通知设置接口模块

**功能定位：** 提供当前用户通知设置的查询和修改能力。

**职责范围：**

- 查询当前用户通知设置。
- 修改订单通知和营销通知开关。
- 如果用户没有设置记录，返回默认设置。

**接口示例：**

### GET /api/user/notification-settings

响应：

```json
{
  "code": "200",
  "msg": "success",
  "data": {
    "orderNotifyEnabled": true,
    "marketingNotifyEnabled": false
  }
}
```

### PUT /api/user/notification-settings

请求：

```json
{
  "marketingNotifyEnabled": false
}
```

**Service 关键逻辑：**

1. 从用户上下文获取当前用户 ID。
2. 查询通知设置记录。
3. 不存在时返回默认值：订单通知开启，营销通知关闭。
4. 更新时只修改请求中传入的字段。
5. 未登录时返回统一未登录错误。

**验收方式：**

- [ ] 未登录访问接口返回 401。
- [ ] 新用户查询时返回默认设置。
- [ ] 关闭营销通知后再次查询能看到关闭状态。
